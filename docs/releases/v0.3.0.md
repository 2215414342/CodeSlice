# CodeSlice v0.3.0

本地优先的 AI 代码阅读桌面应用。边读代码边提问，回答带可点击的源码引用；写文件和执行命令始终由你逐条授权。

v0.3.0 把代码阅读接上了 Git：可以只读查看任意分支、标签或提交，笔记里的代码引用能回到写作时的版本，而不会把你正在操作的工作区一起带走。

## 安装说明

### Windows

1. 下载并运行 `CodeSlice-0.3.0-Setup.exe`。
2. 若出现“Windows 已保护你的电脑”，点「更多信息 → 仍要运行」。
3. 安装器默认按当前用户安装，可自行选择目录。

### macOS

1. 下载对应芯片的 `.dmg`：Apple Silicon 选 arm64，Intel 选 x64。
2. 打开 DMG，把 CodeSlice 拖进「应用程序」。
3. 首次启动若被 Gatekeeper 拦截，右键 CodeSlice →「打开」，或执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/CodeSlice.app
   ```

4. 应用仅做 ad-hoc 签名、未使用 Developer ID、未公证；系统可能会要求你在「隐私与安全性」里再次确认。

### Linux

AppImage：

```bash
chmod +x CodeSlice-0.3.0-x86_64.AppImage
./CodeSlice-0.3.0-x86_64.AppImage
```

若提示缺少 FUSE，安装 `libfuse2`，或使用解包运行：

```bash
sudo apt install libfuse2
./CodeSlice-0.3.0-x86_64.AppImage --appimage-extract-and-run
```

deb / rpm：

```bash
sudo apt install ./CodeSlice-0.3.0-amd64.deb
sudo dnf install ./CodeSlice-0.3.0-x86_64.rpm
```

arm64 机器请换成对应的 `arm64` / `aarch64` 文件名。

## v0.3.0 更新

- **Git 版本视图**：顶部版本选择器会标出工作区当前分支；可以切到任意分支、标签或提交，只读查看那一版的代码、文件树、图谱和符号导航，不 checkout、不改动工作区。
- **只读源代码管理**：新增“源代码”侧栏，按提交查看更改文件、增删行和提交时间线；点开文件可用 Monaco 双栏对照该提交与其第一父提交。工作区视图列出未提交更改。
- **笔记跟着 Git 走**：每条笔记记录写作时的提交；查看某个版本时，会区分“当时已存在”与“此后新增”，并重算每处引用的状态（一致、移动、历史、已修改、已删除）。
- **引用回溯**：笔记里的代码片段在最新代码中不存在时，点击引用会打开写作提交的只读文件和高亮行；顶部工作区、文件树以及你选择的版本保持不变，只有代码标签和源代码管理栏跟着这次查看移动。需要整页切换版本时，仍从版本选择器或提交时间线显式操作。
- **历史导航**：在历史版本的代码里，F12、引用列表和 hover 也使用该版本的符号索引，不会跳回工作区。
- **发布**：版本号统一到 0.3.0，标签为 `v0.3.0`。

升级不会修改你的仓库：版本视图只从 Git 读取内容，不执行 checkout、stash 或 reset，笔记、批注、对话和索引仍保存在本机数据目录。

## 系统要求

- Windows 10（1809+）/ Windows 11。
- macOS 11+（Apple Silicon 或 Intel）。
- Linux x86_64 / arm64，Ubuntu 22.04+ 或 Debian 12+。
- 需要配置兼容的模型服务与自己的 API Key；应用本体、索引和对话数据都保存在本机。

**English:** CodeSlice is a local-first AI code-reading desktop app. v0.3.0 adds read-only Git revision views for branches, tags, and commits, a read-only Source Control sidebar with commit timelines and two-pane diffs, and Git-aware notes. A note reference whose code is gone from the latest worktree opens the writing commit read-only at the old lines; the worktree, file tree, and selected revision stay where they are, and only the code tab plus Source Control sidebar follow the local historical view. Historical files use that revision's symbol index for definitions, references, and hover. All packages are unsigned; see the installation sections above for the Gatekeeper/FUSE steps.
